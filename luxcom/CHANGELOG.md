# LuxCom 원격 클라이언트 빌드 기록

> 버전 표기: `v1.4.6.N` = RustDesk 베이스(1.4.6) + 우리 빌드번호 N(kLuxComBuild). 소비자/기사 좌패널 하단에 표시.
> (구 형식 `MMDD-N` 은 0608-3 까지) 패치할 때마다 N을 올리고 여기에 기록한다.

## v1.4.6.2 (2026-06-09)
- **광고 전면 제거**: 시작 시 자체광고창 + 좌패널 홍보배너 모두 삭제(소비자·기사). 클라이언트에 광고 일절 없음.
- **"이 PC 정보" 창 가로 2배(600px) 확대** — 소비자(좁은 창)는 열 때 창을 잠시 넓히고 닫을 때 복원.
- **PC 정보에 RAM·그래픽카드·메인보드·바이오스 버전 추가** — 콘솔창 없이 Win32 API/레지스트리(GlobalMemoryStatusEx·RegGetValueW HKLM, dart:ffi)로 수집. 못 읽으면 조용히 생략.

## v1.4.6.1 (2026-06-09, 구 빌드 0608-4)
- **접속현황 실시간화**: 소비자 보고 15→5초, 기사 폴링 4→2초, 서버 만료(PRESENCE_MS) 40→16초 → 접속/정상해제 ~2초, 비정상 종료도 ~16초면 대기목록에서 사라짐(기존 최대 40초).
- **소비자 창 확대**: 폭 280→320(높이는 콘텐츠 자동), '이 PC 정보' 버튼 잘 보임.
- **소비자 ⋮(설정) 제거**: 고객이 설정에 못 들어가게(기사용은 유지).
- **버전 표시 신설**: `v1.4.6.1`(+작게 'RustDesk 1.4.6 기반') — 소비자·기사 패널 하단. 스탠바이 카드의 기존 '버전…빌드' 라인 제거(채널만 유지).
- **광고/홍보 슬롯 자리 마련**: 소비자·기사 좌패널. 데스크탑 앱은 애드센스/3rd-party 광고 금지(정책·백신)라 자체 쇼핑몰 배너(클릭→luxcom.co.kr) placeholder, 추후 콘텐츠만 교체.

## 0608-3 (2026-06-08)
- **이 PC 정보** 버튼 추가(소비자 스탠바이 카드 + 기사 좌패널) — PC 이름·도메인/워크그룹·내부 IP·**외부 IP**·Windows 버전·비트·CPU·논리 코어를 한 화면에서 확인 + 전체 복사. 기사가 원격 붙은 PC 환경(특히 IP)을 장치 설치 등에서 즉시 파악. 외부 IP는 luxauth `/api/ip`(공인 IP 반환) 사용, 순수 Dart 수집이라 콘솔창 안 뜸. 소비자·기사 둘 다 재빌드.
